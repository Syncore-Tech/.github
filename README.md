# Syncore-Tech/.github

Organization profile and default community health files for [Syncore](https://syncore.vn).

- `profile/README.md`: the page shown at [github.com/Syncore-Tech](https://github.com/Syncore-Tech)
- `profile/assets/`: light and dark banners built from the official logo (`syncore-lp/static/logo.svg`)
- `SECURITY.md`: default security policy for every repo in the org
- `scripts/apply-org-branding.sh`: sets the org profile fields and public repo metadata
